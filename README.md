# AS9 - Menu & Navigation 📱

Proyek ini adalah aplikasi Android yang fokus pada implementasi sistem navigasi dan berbagai jenis menu sesuai standar desain Material Design. Dibuat sebagai bagian dari tugas praktikum/assignment (AS9).

## 🚀 Fitur Utama
* **Options Menu**: Menu utama pada App Bar untuk akses cepat.
* **Context Menu**: Menu interaktif saat menekan lama pada elemen list/item.
* **Popup Menu**: Menu yang muncul secara dinamis pada komponen tertentu.
* **Navigasi Antar Halaman**: Perpindahan antar Activity atau Fragment dengan intent dan navigation component.

## 🛠️ Tech Stack
* **IDE**: Android Studio
* **Language**: Java / Kotlin (Sesuaikan)
* **UI**: XML Layout & Material Components

## 📂 Cara Menjalankan
1. Clone repositori ini:
   `git clone https://github.com/bayydstywn-dev/AS9-Menu_And_Navigation.git`
2. Buka di Android Studio.
3. Jalankan 'Sync Project with Gradle Files'.
4. Klik 'Run' untuk mencoba di Emulator atau HP fisik.
